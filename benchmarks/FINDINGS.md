# Benchmark findings (2026-11-23)

These are issues the benchmark work surfaced that affect the numbers. The severity is for the demo and the Devpost claims.

| # | Severity | Owner | Finding | Effect on benchmarks |
|---|---|---|---|---|
| B1 | **High** | Louis (`packages/core/src/cost.ts`) | `PRICES['gemini-3.5-flash-lite']` is `{0, 0}` (TODO placeholder). The official rate is $0.30 / 1M input and $2.50 / 1M output (paid tier, ai.google.dev/gemini-api/docs/pricing, read 2026-11-23). | The app UI and Firestore run summaries would show $0.00000 for cloud and hybrid. The harness doesn't use these numbers: it prices tokens with `benchmarks/pricing.json`. |
| B2 | Medium | Avenger (`apps/web/src/stages.ts`, `usage()`) | Output tokens come from `candidatesTokenCount` only, and `thoughtsTokenCount` is dropped. Google bills thinking tokens at the output rate. | Cost is undercounted if the model thinks. Fix: `outputTokens = candidatesTokenCount + (thoughtsTokenCount ?? 0)`. |
| B3 | Medium — **decided 2026-11-23: OCR goes verbatim, de-id becomes a separate stage; harness scores the raw OCR stage by name (CONTRACT.md §2)** | Avenger / Louis | `READ_PROMPT` tells the model to replace names, phones and IDs with `[REDACTED]` *inside the OCR transcript*. The AMR references keep those strings (e.g. "Patient name: E.J", "Hospital number: 2023/BF/057"). | CER/WER count redactions as OCR errors, so all three modes look worse than they are. `readingText` skips deid *stages*, but here the redaction happens inside the read stage. Options: get an unredacted read for scoring, or have Rachel mark PHI spans in references so they can be masked on both sides. |
| B4 | Low | Avenger (`stages.ts`) | Self-reported `bytesSent` = prompt + base64 length. It leaves out the JSON envelope and headers, and the Firebase Auth, App Check and Remote Config calls. | Informational. The harness measures egress independently in Chrome and keeps the self-report alongside for comparison. |
| B5 | Medium | Rachel (`datasets/`) | EkaCare is gated on HF, and `datasets/ekacare` holds only DATASET_CARD.md. EkaCare also has no transcriptions or structured labels, only rubrics. | No EkaCare run is possible yet. Even once imported, it gives latency, cost and bytes only. No dataset has `referenceDoc` yet, so field accuracy can't be computed anywhere. |
| B6 | Info | Sumit | The shared box can't run Gemini Nano: no GPU, 15.6 GiB RAM, and Chrome 156 `LanguageModel.availability()` = `"unavailable"`, both headful and headless. | Device and hybrid modes need an eligible machine. See README. |
