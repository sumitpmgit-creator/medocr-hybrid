# MedOCR Hybrid — taglines

## Recommended

**Only de-identified text ever leaves the device.**

Why this one: it is the product rule, not a metaphor. A judge can remember it after the video, and the demo either proves it or it doesn't. “Device” stays accurate if we submit a Chrome web app, an Android app, or both. If we ship a phone app and want the word “phone” in the line, use alternative 1.

## Alternatives

1. **Only de-identified text ever leaves the phone.**  
   Same promise, more concrete, but only use it if the recorded demo is actually on a phone.

2. **Read the prescription on your device. The cloud never sees the name, the ID, or the photo.**  
   Spells out what is withheld. Slightly long for a Devpost subtitle; strong as a video hook.

3. **On-device first, cloud only for de-identified doubt, a human when the models disagree.**  
   Describes the three-stage hybrid clearly. Better as a subheading than as the one-line tagline.

4. **Medical OCR you can measure: accuracy, cost, and every byte that leaves the device.**  
   Leans on the split-screen comparison and the scoring story. Use if we have a real numbers table; don't lead with this if the table is still `[TBD]`.
